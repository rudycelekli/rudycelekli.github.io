# ADR 0002 · Lead with accepted upstream work

## Context

The first portfolio revision led with a single Gradia study. The portfolio should give open-source impact the opening and give independent research, forward-deployed work and enterprise engagements distinct space.

## Decision

Lead with merged pull requests and a contribution distribution built from the same data as the public evidence ledger. Show per-repository contributor ranks and direct links to accepted fixes. Use scroll-linked study readouts for Gradia and an adjacent comparison of Axiom Consulting and Snorkel AI. Name only organizations that appear in Gradia's public account of the team's enterprise experience and in Rudy's résumé. Render all essential claims and links in HTML.

## Alternatives

An autoplay showreel could convey visual energy but would tie the order and speed of reading to a timer. Animating every section would compete with the outcomes. The implementation uses discrete entrances and a scroll-driven indicator within the current research study.

## Consequences

The chart loads with the existing evidence file and uses one trace per project with merged work. Stats remain readable if the fetch fails. Reduced-motion settings suppress animated transitions and the continuously changing study progress indicator. Named engagements are tied to the existing public record.

## Validation

Passed 19 Python tests and 8 Node tests. Chrome verified seven viewport widths, chart data and its fallback, research progress while scrolling, motion and reduced-motion modes, section navigation, links to local evidence and the printable résumé.
