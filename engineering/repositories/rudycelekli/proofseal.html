proofseal · Behavioral regression memory for coding agents

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A code change can preserve the existing unit suite while changing an observable behavior that the suite never pinned.

Design and implementation

ProofSeal records behavioral baselines as seals and exposes comparisons over MCP, a CLI, and CI. It returns different statuses for drift, regression, and missing evidence so an agent can tell when a baseline is unavailable.

Evidence and scope

The pinned documentation describes comparison, history, and bisection. The checks depend on the coverage and determinism of the behaviors that are sealed.
