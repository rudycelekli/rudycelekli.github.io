rcode · Receipts and undo in an extensible coding agent

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Model and tool flexibility increase the number of actions a user needs to inspect and potentially reverse.

Design and implementation

rcode exposes terminal and command-center interfaces with configurable model routes. The project describes turn receipts, approval controls and undo for file changes.

Evidence and scope

The pinned documentation describes those interfaces and controls. Provider behavior and permission enforcement require tests with the chosen configuration.
