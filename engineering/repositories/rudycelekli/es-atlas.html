es-atlas · Separating an agent persona from deployment wiring

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A consulting assistant needs editable role instructions alongside a repeatable way to package its runtime.

Design and implementation

Atlas keeps the role in a skill document and the runtime in deployment and entrypoint files. A nested consulting skill contains Python code and a memory module.

Evidence and scope

The pinned tree supports the packaging design. Instructional examples in the repository are not deployment evidence.
