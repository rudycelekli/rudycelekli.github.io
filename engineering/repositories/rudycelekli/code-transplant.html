code-transplant · Moving a TypeScript parser with a behavioral reference

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A parser can compile after extraction and still change outputs when its dependency environment shifts.

Design and implementation

Code Transplant extracts a named parser with a dependency capsule and explicit adapter. It compares the adapter against the unchanged source parser on concrete inputs and preserves a verification record.

Evidence and scope

The source documents a replayable comparison. Agreement is scoped to the observed inputs and the selected parser.
