Owned public project · rudycelekli/swarmwatch

swarmwatch · Live topology for multi-agent runs

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Observing a swarm from logs after the run makes it difficult to see active relationships, costs and alarms while work is in progress.

Design and implementation

SwarmWatch documents two mechanisms. Process-live launches and supervises an agent command, while stream-live follows an event stream from a running system. The interface renders topology and controls from those inputs.

Evidence and scope

The project documents both collection modes. Control and data completeness depend on which process or stream is attached.
