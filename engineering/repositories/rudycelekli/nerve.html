Owned public project · rudycelekli/nerve

nerve · Baseline comparison for steady machine sounds

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A periodic sound check is easier to interpret when it is compared to a normal recording taken from the same position.

Design and implementation

NERVE analyzes audio locally in the browser and compares numeric features of the baseline and later recording. It highlights which parts of the sound changed.

Evidence and scope

The README describes the capture protocol and local comparison. Fault diagnosis and field accuracy require ground-truth machine data.
