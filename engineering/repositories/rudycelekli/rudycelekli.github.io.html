Problem

An evidence dashboard can mix identity claims, time-varying activity counts, and links to accepted changes in ways that obscure their sources.

Design and implementation

The site keeps visible identity aligned with structured Person and ProfilePage data and refreshes public contribution evidence separately. It provides raw HTML, Markdown, JSON, and an Atom feed for different readers.

Evidence and scope

The pinned README describes provenance and the refresh pipeline. Crawl access, indexing, and search referrals are measured separately.
