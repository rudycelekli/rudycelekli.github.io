gradia-blocks · Reviewable admission for reusable capabilities

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Reusable components can carry implicit tenant, event, and retry assumptions into workflows that depend on them.

Design and implementation

Gradia Blocks packages runnable references for Feedback, Work Items, Event Relay and Outbox. A separate admission screen evaluates candidates, and source-pinned Skills describe how to use the references.

Evidence and scope

The repository documents these component contracts and admission mechanics. Deployment and isolation properties depend on the consuming implementation.
