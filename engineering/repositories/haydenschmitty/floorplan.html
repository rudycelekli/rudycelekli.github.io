Upstream contribution · haydenschmitty/floorplan

floorplan · Mapping routes through real framework boundaries in Floorplan

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A codebase map can make incorrect inferences if it mistakes syntax for evidence. Floorplan lost Hono routes after reading a wildcard inside a string as a comment. Django child routes lost their mount prefix, while Express checks could leak from one route into the next.

Engineering response

The changes preserve source positions while recognizing quoted strings, interpret Django include calls as mounts, and scope each Express middleware scan to that route call. Where the route uses a separately named handler, the extractor excludes the handler from the middleware list.

Evidence and scope

The PRs include fixtures with a Hono wildcard, a Django orders mount, and Express routes using named handlers. The recorded outputs show the affected routes appearing and the Express fixture identifying its actual unchecked routes. This evidence concerns static extraction from those fixtures.
