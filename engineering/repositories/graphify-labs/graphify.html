graphify · Resolving Python graph edges to the method named in source

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Graphify assigned separate identifiers to methods such as run and _run, but the member-call resolver folded the names together when choosing a target. A valid call could therefore point to the wrong node in the graph.

Engineering response

The attributed fix resolves a member call using the method spelling. Related commits harden evidence checks for mis-cased confidence values and keep parallel relations when exporting Obsidian notes.

Evidence and scope

The upstream commit records preserve the implementation and attribution. The cases concern graph fidelity at extraction and export boundaries, and provide no measured claim about retrieval performance.
