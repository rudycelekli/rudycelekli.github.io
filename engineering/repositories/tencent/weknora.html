WeKnora · Reassembling multiline provider events in WeKnora

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A valid model-provider SSE packet can split its JSON across several data lines. Decoding each line as a standalone packet could lose the provider response.

Engineering response

The reader assembles incomplete packets, recognizes a leading BOM and multiple line-ending formats, and applies the existing 1 MiB limit to the assembled data. Complete packets can still arrive during an open connection.

Evidence and scope

The PR reports 25 passing focused cases, including open io.Pipe streams, partial reads and size limits. It records broader local checks blocked by uncached dependencies.
