ai-job-search · Keep hidden markup out of job-research text extraction

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The job research retry could expose text from an HTML template or an unclosed script block to its agent context. A truncated fetch was enough to surface text a browser would not display.

Engineering response

Reuse the posting guard's hidden-block handling in the text-extraction path. Treat an unclosed hidden block as extending to the end of the input and keep visible text after properly closed blocks.

Evidence and scope

The pull request records a failing-then-passing extraction regression and 837 local tests passing with 30 skips. It separately reports four hosted CLI typecheck failures on unchanged code.
