craft-anything · Representing missing ACP token counts in Craft Anything

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Craft Anything showed zero tokens when an ACP agent supplied no per-turn counts. ACP context occupancy is a different measure and cannot establish input or output usage.

Engineering response

The CLI and activity feed represent unknown turns explicitly. Project and session totals retain counts that were actually reported and display a lower bound when some turns remain unknown.

Evidence and scope

The PR reports an ACP fixture and a desktop save-and-reopen case. The AI crate and CLI suites passed locally, and the merge record describes an unrelated engine fixture failure.
