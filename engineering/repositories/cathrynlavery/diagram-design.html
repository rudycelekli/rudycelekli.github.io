diagram-design · Preserving type syntax in draw.io imports

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A plain draw.io label such as List<U> could lose its type parameter when the importer treated angle brackets as HTML. Applying entity decoding twice could also change the intended label.

Engineering response

The importer now checks each cell's html=1 style before applying HTML cleanup. That decision covers node labels, edge labels and labels on edge children.

Evidence and scope

The merged contribution reports an import verifier with plain-text and HTML controls, plus the project's local validation commands. The report discloses Codex assistance.
