hermes-agent · Revalidating worktree state before Hermes cleanup

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Worktree state can change between checking it and actually removing it. Cleanup needs to keep its decision tied to the current worktree state at the point the potentially destructive action runs.

Engineering response

The attributed Hermes commit revalidates cleanup gates before removing a worktree. Other upstream commits by the same contributor reject nonstandard JSON before file writes and reject negative retention before pruning backups.

Evidence and scope

The default-branch commit records establish the source changes and include their cherry-pick provenance. This case documents the guard and leaves production usage unmeasured.
