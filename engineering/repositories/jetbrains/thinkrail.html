thinkrail · Preserving unsent image drafts when ThinkRail chats remount

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Switching tabs unmounted the chat composer. Its text draft survived because it belonged to the session, but pasted and attached images disappeared with the UI component.

Engineering response

The change moves attachment drafts and their pending decode state into the corresponding chat runtime. Accepting a submission clears the draft, and resetting or replacing the runtime prevents an old decode from restoring an attachment to a closed session. A second PR fixes Markdown list markers in settled answers.

Evidence and scope

The image PR records before/after browser screenshots and covers remounts, isolation across chats, submission reset and pending decodes. The list PR documents browser checks for wrapping, nested lists and exact-source clipboard output.
