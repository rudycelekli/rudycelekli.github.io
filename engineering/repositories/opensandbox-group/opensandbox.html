OpenSandbox · Clean up stale Jupyter contexts after a sandbox restart

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

OpenSandbox kept a cached code context when Jupyter's delete endpoint returned 404. If Jupyter restarted or otherwise lost its session, repeated deletes failed and bulk cleanup stopped at the stale context.

Engineering response

Classify the missing session as already absent and remove local context entries. Other Jupyter failures keep the existing error path.

Evidence and scope

The pull request reports a regression using an HTTP test Jupyter server that returns 404 and passing existing creation and deletion suites afterward.
