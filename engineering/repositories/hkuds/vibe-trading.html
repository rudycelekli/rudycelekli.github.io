Vibe-Trading · Require enough observations for strict factor statistics

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A single information-coefficient observation in Vibe-Trading could produce a success row with NaN sample deviation. Strict JSON consumers could not serialize that result.

Engineering response

Use the same minimum sample size as the ordinary factor runner. The strict path records one-observation alphas as skipped and keeps its existing empty-series reason.

Evidence and scope

The pull request reports a baseline failure and 44 passing strict-runner tests after the change. The new test serializes the result with strict JSON settings. The checks are offline.
