Upstream contribution · e2e-inc/e2e

e2e · Collect several browser downloads from one test action

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

An export can produce multiple files from a single click. The existing single-download path also let a stalled file transfer outlive its timeout.

Engineering response

Add a collector that runs one trigger and gathers the requested number of downloads in start order. Use one timeout for start, completion and saving, and clean up started transfers when the wait aborts.

Evidence and scope

The pull request reports local Chromium and provider-path fixtures covering multiple files and stalled transfers, with 609 passing web-package tests.
