CCBaga · Passing literal known_hosts paths to OpenSSH from CCBaga

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

OpenSSH reads UserKnownHostsFile values with its own quoting rules. A valid filename containing a double quote could make that parser fail before a connection attempt began.

Engineering response

CCBaga escapes quotes and backslashes inside the quoted path, keeping the whole setting in a single -o argument.

Evidence and scope

The focused tests call local ssh -G and compare the parsed path for embedded spaces, a quote and a backslash. The run exercised configuration parsing without a VPS connection.
