claude-mem · Restore project merges when importing memory

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A claude-mem export retained the destination project of merged observations and session summaries. The import dropped that link, so restored records disappeared from searches and context scoped to the merged project.

Engineering response

Persist the merge destination on both imported row types and invalidate context for the destination project. Keep that mutable field outside the matching logic so an earlier export still matches a record that has since moved.

Evidence and scope

The pull request reports a failing regression on the original import path, followed by 352 passing tests across SQLite, project merge, context caching and semantic persistence.
