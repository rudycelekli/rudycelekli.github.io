lz4 · Reading complete short skippable LZ4 frames

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The file reader applied the normal-frame minimum header size before distinguishing skippable frames. A complete eight-byte frame with an empty payload could therefore be rejected as if it were a truncated normal frame.

Engineering response

The reader parses the frame type before applying the normal-frame minimum, allowing short but complete skippable frames. A separate Meson patch sets the C language for two static-library options that previously failed during configuration.

Evidence and scope

The frame PR reports 189 passing tests in each of the serial and multithreaded unit builds, including a matrix across all 16 skippable magic values and short payloads. The Meson evidence covers setup for both options and compilation for the endianness option. The allocation-disabled build still exposed a separate compilation issue.
