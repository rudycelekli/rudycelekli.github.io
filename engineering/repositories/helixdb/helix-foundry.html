Upstream contribution · HelixDB/helix-foundry

helix-foundry · Keep a completed Helix Foundry answer when Stop arrives late

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A cancellation request could arrive just after an analyst run completed and overwrite its successful status. The saved answer remained, but follow-ups disappeared and retry could re-run the question.

Engineering response

Refuse cancellation of a succeeded run with a conflict response and leave its answer and status in place. Preserve cancellation behavior for active runs and repeated requests for stopped runs.

Evidence and scope

The PR reports 11 passing thread tests and passing related route checks. The regression exercises an already-completed run at the API boundary.
