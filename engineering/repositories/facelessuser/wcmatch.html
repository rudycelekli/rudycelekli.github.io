wcmatch · Interpreting an empty glob root as the current directory

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A caller passing an empty string or empty bytes for root_dir could get different results than a caller using the expected current directory. The behavior also mattered when the calling process supplied a directory file descriptor.

Engineering response

The attributed upstream commit treats either empty root representation as the current directory, including within the directory descriptor's scope. It uses native path separators in test expectations to reflect Windows and POSIX behavior.

Evidence and scope

The upstream commit contains the regression and changelog entry. Its coauthor trailers credit Isaac Muse and Claude Sonnet 5.5 alongside the attributed contribution.
