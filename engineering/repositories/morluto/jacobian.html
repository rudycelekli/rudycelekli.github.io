jacobian · Installing Jacobian in the active Claude Code profile

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Jacobian setup wrote configuration and skills under the home directory even when CLAUDE_CONFIG_DIR pointed Claude Code at a separate profile. Setup could report completion while the active profile saw neither installation.

Engineering response

The setup and detection code use the selected directory for .claude.json and skills, falling back to the home-directory layout when no override is configured.

Evidence and scope

The PR describes isolated setup tests for custom and default profiles. The result covers local configuration paths.
