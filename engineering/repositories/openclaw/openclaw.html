openclaw · Keeping Feishu code examples intact in OpenClaw agent context

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

An incoming Feishu code block containing triple backticks could prematurely close the Markdown wrapper. An agent then received code and unintended prose as separate pieces.

Engineering response

The Feishu renderer selects a fence longer than any backtick run in the message's code, with a minimum of three.

Evidence and scope

The merge record documents a built Gateway with a local HTTPS Feishu fixture and signed webhook inputs. An independent parser recovered one intact code node in the corrected capture. The capture intercepted the message before model execution.
