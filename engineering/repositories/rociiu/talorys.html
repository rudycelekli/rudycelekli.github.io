Upstream contribution · rociiu/talorys

talorys · Keeping recent edits when importing a Talorys backup

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Importing an older backup could silently replace newer local task, project and note text because their upserts overwrote existing rows without checking recency.

Engineering response

The backup importer updates those three record types only if the incoming timestamp is strictly newer, extending the rule that already protected memory records.

Evidence and scope

A focused regression in the merge record restores stale versions of all three record types and checks that local edits survive. A newer note then confirms that legitimate updates can still import.
