agentic-qe · Keep generated tests out of Agentic QE execution results

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The MCP test generator returned code and also stored each generated object as a test outcome. In that path, defaults could create a passing result and an execution duration before any test ran.

Engineering response

Remove the execution-result insertion from the generation path. Preserve generated code in the response and keep measurement paths for observed execution and coverage.

Evidence and scope

The pull request reports that six generation regressions failed on the original handler factory and all 32 cases passed after the change. The fixture mocks the factory's dependencies.
