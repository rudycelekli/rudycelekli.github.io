Upstream contribution · deeplethe/utopia

utopia · Interpret numeric weekdays consistently in Utopia schedules

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The Advanced scheduling field advertised standard cron while the evaluation library mapped numeric weekdays differently. An expression entered as Monday through Friday could fire Sunday through Thursday.

Engineering response

Normalize numeric weekday expressions to named weekdays using standard cron semantics before storing new values. Previously stored numeric expressions keep their original behavior until resaved.

Evidence and scope

The pull request reports a baseline Sunday firing and a corrected Monday firing in an isolated Rust fixture pinned to the scheduler library. It does not report a full workspace build.
