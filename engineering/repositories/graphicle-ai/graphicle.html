graphicle · Returning the correct JSON-RPC error for unavailable Graphicle methods

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A workspace MCP connection returned Invalid params when it received a method that the connection did not expose. That made capability absence indistinguishable from an invalid request to a supported method.

Engineering response

The dispatch layer now returns -32601 for an unavailable method. Errors such as an unknown tool within tools/call still use -32602.

Evidence and scope

The merge record reports 690 local Rust tests and identifies a workspace-scope control for both error codes.
