agent-beacon · Preserve exact JSON-RPC IDs through agent-beacon

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Decoding a request ID through float64 rounded some large integers. Two distinct client requests could receive the same response ID, interfering with response routing.

Engineering response

Retain numbers as json.Number and echo their exact JSON value in success and error responses. String IDs and dispatch behavior continue to use the existing path.

Evidence and scope

The pull request reports 24 transport cases through stdio and loopback HTTP, with eight baseline failures. The fixed package passed its ordinary and race checks locally.
