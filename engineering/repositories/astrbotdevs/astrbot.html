AstrBot · Keeping Telegram sender names useful in AstrBot context

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Telegram permits accounts without a public handle. AstrBot represented every such sender as Unknown in history, model context and the nickname available to plugins, despite having a display name.

Engineering response

The adapter selects the Telegram username first, then the display name, then Unknown. This preserves the existing username convention for accounts that already provide one.

Evidence and scope

The pull request reports a parametrized adapter regression across the username, display-name and empty-data cases, with 56 passing Telegram adapter tests. Telegram production usage is outside that test evidence.
