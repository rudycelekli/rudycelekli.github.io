Upstream contribution · bee-san/RustScan

RustScan · Preserving TOML and script metadata semantics in RustScan

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Documented lowercase script modes were rejected by the config reader. The script metadata reader also removed every hash from a line, changing values such as language tags and URL fragments.

Engineering response

The parser accepts documented lowercase aliases alongside the existing variant names and continues to reject unknown strings. Script metadata extraction removes only the leading comment marker, leaving embedded punctuation for TOML to interpret.

Evidence and scope

The config PR exercises the public Config::read path through temporary files and reports a baseline where the three lowercase cases fail. The metadata PR uses the real parser with a temporary fixture and checks the complete command-format string without executing it or scanning a network.
