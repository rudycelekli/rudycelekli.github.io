Ciphey · Keeping JavaScript character codes distinct from byte sequences in Ciphey

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Ciphey stripped String.fromCharCode from decimal input and treated its arguments as UTF-8 bytes. The same integers can represent different text under JavaScript's UTF-16 rules.

Engineering response

The decoder retains the explicit JavaScript interpretation and applies its code-unit conversion in the supported numeric grammar. Bare decimal input follows the byte-decoding path.

Evidence and scope

The PR used Node as an independent oracle for ambiguous values and surrogate controls. It reports 2,420 local Rust tests passing and separately discloses an owned qualification run marked failed for its spelling command.
