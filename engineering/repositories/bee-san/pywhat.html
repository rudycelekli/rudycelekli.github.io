pyWhat · Scanning literal directory names in pyWhat

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Recursive identification interpreted user-supplied path components as part of a glob. A directory named scan[2026] could be skipped, while an asterisk could select an unintended sibling.

Engineering response

The identifier escapes the directory path before appending the recursive glob, keeping glob syntax limited to the search portion it adds.

Evidence and scope

End-to-end fixtures verify discovery in the selected directory and absence of decoys from a sibling. The recorded cases went from three failures to three passes.
