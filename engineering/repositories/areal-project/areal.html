AReaL · Passing local worker environment values without losing delimiters

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The local scheduler serialized an environment dictionary into comma-separated key-value pairs. Commas in CUDA allocator settings and equals signs within values could then cause splitting errors before the worker launched.

Engineering response

The local scheduler passes the original mapping into the launcher utilities. The string interface remains available and splits a pair only on its first equals sign.

Evidence and scope

The PR reports nine passing launcher tests, including two cases that fail without the correction. This validation runs in CPU-only tests and does not exercise launching a GPU worker.
