OpenMontage · Keeping usable OpenMontage assets in a size-limited cache

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A generated image larger than the entire cache could push out every smaller asset and still leave the cache over its configured limit.

Engineering response

The cache checks the size of a new entry before least-recently-used eviction. Diagram generation can still return the valid image because cache admission is optional.

Evidence and scope

The PR reports a local Pillow diagram reproduction with a 512-byte cache, a roughly 2.4 kB output and a previously cached 76-byte image. The corrected path preserves both the generated output and the cached image. The checks ran offline.
