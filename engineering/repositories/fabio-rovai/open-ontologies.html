open-ontologies · Reject truncated XML before loading ontology records

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A cut-off XML document could contain one complete record and one unfinished record. The importer loaded the completed prefix and reported success, concealing lost data.

Engineering response

Reject end-of-file while element depth remains open, before mapping or loading records. Preserve valid handling of complete documents, including self-closing elements, CDATA and empty fields.

Evidence and scope

The PR records nine passing Linux integration checks after eight baseline failures. The validation includes the built command-line tool and file-dispatch paths.
