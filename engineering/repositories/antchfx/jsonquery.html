Upstream contribution · antchfx/jsonquery

jsonquery · Preserving JSON values through text and XML serialization

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The Go JSON query library printed a native nil as Go's <nil> placeholder, although the original JSON value was null. XML serialization also wrote carriage returns literally, letting the XML parser normalize them to line feeds on a round trip.

Engineering response

The text representation uses JSON's null spelling while retaining the native nil value. XML output writes carriage returns as character references so consumers can parse the original string back.

Evidence and scope

The two PRs report baseline-failing regression tests and successful full Go and race runs. The fixtures distinguish null from the string null, false and zero, and exercise carriage returns alongside CRLF, tabs and XML metacharacters.
