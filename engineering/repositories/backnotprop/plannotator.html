plannotator · Opening a review note without accidentally posting the decision

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

Plannotator used Mod+Shift+Enter to open a note in plan review, but code review shared the primary submit handler without inspecting Shift. A reviewer following that shortcut could post an irreversible decision before entering the note.

Engineering response

The review editor registers the note action and routes the shifted chord to the composer. The unshifted shortcut remains associated with the primary decision.

Evidence and scope

The PR records a DOM regression that detects a submitted decision on the baseline and expects an open composer with no submission on the repaired path. The case covers the editor's keyboard behavior.
