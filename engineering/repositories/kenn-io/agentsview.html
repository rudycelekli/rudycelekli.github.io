Upstream contribution · kenn-io/agentsview

agentsview · Reading compressed OpenClaw transcripts without blocking host sync

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

OpenClaw's transcript schema allows plain event JSON or a compressed zstd blob. Scanning a NULL JSON column into a Go string stopped host synchronization as soon as AgentsView encountered a compressed event.

Engineering response

The parser checks for the compressed column, decodes bounded zstd frames, and fingerprints valid events consistently across plain and compressed storage. Malformed data remains isolated to its own session so healthy siblings can continue.

Evidence and scope

The PR records a real SQLite test database containing alternating plain and compressed events, with equal fingerprints and parsed messages for equivalent data. It reports passing parser and sync tests. The fixture uses standard zstd framing and does not establish compatibility with a captured production archive.
