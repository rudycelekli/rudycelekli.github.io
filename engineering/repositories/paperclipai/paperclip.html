paperclip · Keeping unread agent comments visible in Paperclip inboxes

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

New comments moved an assigned issue forward in recency sorting. By reusing that issue update time as a fallback read receipt, Paperclip could treat the arriving comment as already read and hide it from an assignee's unread inbox.

Engineering response

The maintainer ported the original fix onto the current branch with explicit contributor credit. It uses creation time for the assignee's initial read boundary, preserves explicit read receipts and excludes deleted external comments from unread calculations.

Evidence and scope

The upstream commit describes native PostgreSQL regressions for real comment writes, later assignment and deleted comments. It reports 41 focused tests passing on the frozen head and successful hosted build, typecheck and end-to-end shards. The original PR remains separately linked as provenance.
