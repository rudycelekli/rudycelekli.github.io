Upstream contribution · aindeev/agent-chrome-relay

agent-chrome-relay · Reclaiming Chrome tabs returned after agent disconnect

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A Chrome tab could finish opening after the relay had swept the tabs of a disconnected agent. The late response then registered a tab with no connected owner. The same race affected popups.

Engineering response

The relay marks the agent closed and checks that state before accepting late tab creation. It requests cleanup of the returned tab and drops queued page calls.

Evidence and scope

The PR reports two regressions at the deferred extension RPC boundary and a connected-agent control. The test uses the relay implementation with isolated RPC fixtures.
