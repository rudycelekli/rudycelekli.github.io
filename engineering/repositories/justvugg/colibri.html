colibri · Isolate simultaneous model download jobs in Colibri

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

A millisecond timestamp served as a model download's job ID. When two jobs started in the same millisecond, the second registry entry displaced the first and cancellation could target the wrong worker.

Engineering response

Give each download a separate UUID while retaining the timestamp for display and sorting. The existing cancellation route accepts the resulting hex identifiers.

Evidence and scope

The pull request records two failing-then-passing regressions covering the real local HTTP path and 64 concurrent job registrations on a fixed clock. It reports 28 passing UI gateway tests and one skip, using synthetic download metadata.
