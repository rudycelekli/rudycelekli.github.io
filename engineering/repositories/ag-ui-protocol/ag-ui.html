ag-ui · Preserving pending tool-call IDs in AG-UI's Go SDK

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The Go representation of a successful RUN_FINISHED outcome omitted the pending tool-call IDs. A Go relay could silently drop the information a frontend needed to resume with outstanding results.

Engineering response

The Go model now reads and writes those IDs on the success outcome and keeps them off other variants to match the protocol shape.

Evidence and scope

The upstream fixture round-trips as JSON with the correction. The PR reports a revert-based failure control and 127 passing top-level Go tests.
