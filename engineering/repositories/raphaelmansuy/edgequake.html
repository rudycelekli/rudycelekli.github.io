edgequake · Propagate request encoding failures from the EdgeQuake Swift SDK

Rudy Celekli’s engineering portfolio · AI-assisted summary

Problem

The Swift SDK discarded encoding errors while building HTTP bodies. It could send a POST, PUT or PATCH with the body missing and leave the caller debugging a misleading server error.

Engineering response

Propagate the original encoding error before dispatch and update the multipart caller to handle the throwing request builder.

Evidence and scope

The pull request reports failing-then-passing method regressions that verify no request is sent after an encoding error. It reports 237 passing Swift tests and 22 skipped live end-to-end tests.
